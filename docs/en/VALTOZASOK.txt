WSTATION – CHANGES
=========================

== 2.2.7.2 (2026-10-21) – minor fixes ==
- Manual backup: waits up to 10 minutes even with large data, then gives a clear error.
- Evaporation (ET₀): no longer paradoxically rises on very overcast days.
- Own formula at 5-minute resolution: drawn fully after scrolling and zooming.
- Overview: the "last data day … in this year" title is a whole sentence in other languages too.
- Garden diary: no overflow on phones / narrow windows; for shrubs the unit reads "litres / shrub".
- A damaged settings file no longer blocks the interface; the Drought tab copes with missing data.
- Downloader: METAR data and oversized server replies can no longer damage files; the Viewer's error
  log starts a new file at 5 MB.

== 2.2.7.1 (2026-10-21) – security fixes ==
- Installer: it no longer deletes or moves files that are not its own. A folder counts as a WStation installation
  only if the programs really are WStation's; into a non-empty folder of something else it installs into a new
  "WStation" subfolder. Of the old guides it removes only its own (based on the install list or their title line).
- The interface cannot run code from a damaged or foreign data file: diary, running log and settings values are
  checked before display, and the interface runs with a strict Content Security Policy.
- Only http/https links open from the program window (in the browser); other protocols or files cannot be started.
- Alert settings accept only valid values and cannot damage the Downloader's settings file. The Downloader sends
  the API key only to the Weather Underground HTTPS address.
- Restore from backup: done as one step (on error everything stays as it was), scheduled downloading pauses
  meanwhile; the current API key and station are kept; oversized or out-of-place files are not restored.
- The local interface rejects oversized requests.

== 2.2.6 (2026-10-21) – installer and minor fixes ==
- Installer: if the scheduler has just started the Downloader (e.g. right after creating the task), the installer
  waits up to 90 seconds for it instead of stopping with an error.
- Command-line install (--csendes): without --utemezes the existing automatic download is kept (until now a
  reinstall turned it off); use --utemezes 0 to turn it off.
- Running tab: the ƒx button of the Comfort card also appears with older data.
- The formulas and default-value hints in the formula windows use the decimal separator of the interface language; the repair
  messages of the drought settings are translated too.

== 2.2.5 (2026-10-21) – translation and minor fixes ==
- Translation: the watering advice on the Drought tab, the dew point bands, the "unverified" record mark and the
  "Yes" button of confirmations are whole sentences in English, German and Spanish; default profile names with
  brackets (e.g. "Lawn (sprinkler)") are translated too.
- Formula symbols of the suspicious-measurement rules are language-neutral (e.g. I_jump, P_melt, T_sun).
- On phones the Running and Report tabs no longer scroll sideways; the "Record" buttons on the Drought tab tell
  screen readers the profile name.
- Translation: the tree watering advice, the reliability line of the running advisor, the Location and cloud
  labels, the fire danger classes and the spoken names of the formula buttons are translated too; translated
  sentences no longer end in a double full stop. Even on very narrow (320 px) screens the Drought, Running and
  Settings tabs fit.
- Installer and Viewer: if the Windows Task Scheduler does not respond, they move on after 20 seconds (until now
  they could wait for minutes).
- The formula and settings buttons (ƒx) on the Overview, Timeline, Rain, Wind, Statistics and Running tabs
  now appear in English, German and Spanish too (until now only in Hungarian), and the formula windows are translated.

== 2.2.4 (2026-10-20) – review fixes ==
- Suspicious measurements: new rules for rain jumps (melting snow too) and a frozen anemometer; the maximum
  temperature above the plausibility limit (default 41.9 °C) is marked "unverified".
- Overview: plain-language sentences, exact times in "What changed", stale-data warning follows the download
  schedule. Drought: summary at the top ("water today?"), technical cards in a collapsible section; the Water
  sub-tab has its own period selector.
- Refresh can be cancelled (max. 30 minutes); a second launch brings the running window to the front.
- Backup: copy the latest backup elsewhere and restore from a backup. Excel export in the interface language,
  optionally with raw data. Report: dry / wet compared to the monthly long-term average (Settings › Location).
- Timeline: legend per panel, unit in the panel title, Ctrl + wheel zooms. Beaufort name from the rounded value.
- Accessibility: keyboard-operable dialogs, named charts and fields, own confirmation dialog, skip link.
- Translation: whole-sentence templates, no half-translated sentences. Installer: files are replaced together
  (rolled back on error) while scheduled downloading is paused. Many smaller fixes.

== 2.2.3 (2026-10-20) – cloud cover estimate ==
- Cloud cover estimated from your own measurements (% and okta, likely cloud type), optional METAR check.

== 2.2.2 (2026-10-20) – WStation, location, language-dependent file names ==
- New name: WStation. Settings › Location (name, time zone, coordinates, altitude, heat thresholds, currency).
  Programs and guides are named in the installer language (e.g. Viewer.exe, Downloader.exe).

== 2.2.1 (2026-10-20) – bug fixes ==
- Download, scheduling (also on battery, missed runs caught up), security, cache, drought, statistics, report
  and accessibility fixes.

== 2.1 (2026-10-19) ==
- Multilingual: Hungarian, English, German, Spanish – the interface, the ? and ƒx windows, the charts, the
  Downloader's messages and alerts, the installer and the guides. A new language can be added with one file.
- Units in Settings: °C/°F, mm/inch, km/h – m/s – knots – mph – Beaufort, hPa/inHg. Fractional Beaufort
  (WMO formula); 1 decimal on the Wind tab, 2 for the average wind.
- "Minimum font size" setting (Normal / 14 / 16 / 18 px, slider, Ctrl + / Ctrl −), charts included.
- Statistics: any number of from–to periods, quick buttons (years, previous 365 days, whole period),
  favourites; combined or side by side. "Periods overlaid" with several periods and data types,
  day/week/month/custom.
- ƒx icon next to computed values: formula, explanation, parameters with symbols and standard values,
  reset, named presets. The ? windows reject invalid values and stay open when saving a preset.
- Canadian FWI explained step by step with a "Today's calculation" table; rain as blue dots on the fire chart.
- Depletion %: its own explanation window (bucket analogy, bands, Ks, the profile's own numbers).
- Suspicious measurements card: WU flags and own rules switchable separately, with parameters and a live count.
- Rain gauge calibration with manual readings (any number of from–to periods, Σ manual / Σ station, global
  or per-period factor, error messages such as "is the rain gauge clogged?"); calibrated rain is used everywhere.
- Watering: saved programs (zone, days, amount) and their periods; automatic watering moved here.
- New "Water" sub-tab: water use and demand (target % depletion), cost with one price or water + sewer fee,
  tile calendar, monthly bars, comparison.
- "What changed" bar on the Overview (since yesterday / since the last opening, day by day).
- Settings: custom download schedule (minutes/hours/daily at a time/weekly on days), backup frequency and
  "Back up now", change log with restore, update check (newer installer in or next to the folder).
- Security: the programs only write into their own folder (except the shortcut, the scheduled task and an
  Excel export saved to a chosen place).

== 2.0 (2026-10-19) ==
- Drought tab: Canadian Fire Weather Index (FFMC, DMC, DC, ISI, BUI) with danger classes, vapour pressure
  deficit (VPD), heat sum (GDD) with milestones; water-demand stages can follow the heat sum.
- New Rain tab: rain events (start, length, total, max. intensity), monthly rain, filters.
- New Wind tab: hour × month heatmap, wind rose by knot classes, afternoons above 3 Bft.
- New Statistics tab: clickable records, months compared (with a month-end estimate), hour × day heatmap,
  average daily course by month, two days / weeks overlaid, data quality page.
- New Running tab: comfort index and a learning running-clothing advisor per runner.
- New Report tab: monthly weather report and yearbook, printable / PDF.
- Overview: watch bar (frost, heat, pressure drop, wind, rain, comfort, drought, fire danger, Zambretti
  forecast), sunrise, sunset, day length, moon phase, "The month's extremes" / "On this day".
- Timeline: custom formula band, front and thunderstorm markers, big rains, garden diary entries;
  km/h – knots – Beaufort switch everywhere.
- Calendar: garden diary; watering is included in the soil water balance.
- Downloader: Windows alerts (frost, pressure drop, strong wind, cloudburst, heat) with repeat protection
  and quiet hours; adjustable on the Settings tab with a test notification.

== 1.4 (2026-10-19) ==
- New Drought tab: FAO-56 evaporation (ET₀) and soil water balance per vegetation type, profiles on/off.
- ? button next to every indicator: formula, coefficients with standard values, adjustable here.
- Soil types and own presets; runoff with the SCS method depending on prior saturation.
- Solar radiation correction (suggested from the measured data, also monthly calibration).
- Trees: daily water demand in litres from canopy, trunk and age; lasting water shortage; reserve.
- Watering advice for lawn, drip-watered shrubs and pots; automatic program and "I watered" log.
- Evaporation and depletion can be shown in the calendar.
